# 🧠 Java Code → Human Workflow Diagram

A modern, interactive web application that converts **Java code** into a **human-readable workflow diagram** using **Mermaid.js**. Perfect for visualizing complex Java methods, if-else branches, and try-catch flows in a way **non-technical stakeholders can understand**.

Deployment Link: https://java-code-to-flowchart-generator-jappvbt2nkthnke2ezmofn4.streamlit.app/

---

## 🌟 Features

- **Convert Java code to workflow diagrams** with Mermaid
- **Interactive, scrollable diagrams** in Streamlit
- **Downloadable Mermaid source** for sharing or offline editing
- **Dark, modern UI** with gradient buttons and rounded cards
- Supports **methods, if-else, try-catch** visualization in human-readable form
- Lightweight and easy to run locally

---

## 🛠 Tech Stack

- **Python 3.13+ / 3.14**  
- **Streamlit** – for the interactive web app  
- **Mermaid.js** – for rendering diagrams  
- **Mermaid CLI (optional)** – for generating PNG/PDF if needed in the future  
- **HTML/CSS** – for styling the app

```bash

3. **Install Dependencies**
